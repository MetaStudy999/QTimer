# QTimer Adaptive Learning System 통합 기획서 v1.0

기준일: 2026-08-12
상태: 구현 전 설계 기준안
대상 baseline: 정보처리기사 필기 검증 문제은행 973문항

## 1. 제품 비전

QTimer는 단순 문제은행이나 타이머가 아니라, 사용자의 현재 지식 상태와 시험 중요도를 함께 분석하여 **지금 무엇을, 어떤 방식으로, 얼마나 학습해야 하는지 결정해 주는 적응형 시험 훈련 시스템**을 목표로 한다.

핵심 폐쇄루프는 다음과 같다.

`측정 → 진단 → 우선순위 → 처방 → 학습 → 지연 재측정 → 재진단`

최종 목표는 단순한 즉시 정답률 100%가 아니라 다음을 함께 만족하는 것이다.

- 무힌트 정답
- 적절한 확신
- 목표시간 내 반응
- 지연 후 기억 유지
- 유사/변형 문제 전이
- 과목별 과락 위험 감소
- 실제 CBT에서의 안정적인 수행

## 2. 핵심 설계 원칙

### 2.1 검증 문제은행은 불변 baseline으로 취급

- 현재 검증 완료된 973문항은 `SOURCE BANK`로 유지한다.
- 신규 AI 변형문제는 `TRAINING VARIANT BANK`로 분리한다.
- AI 생성 문제를 실제 기출/공식 출제문제로 표시하지 않는다.
- 원문, 정답, 출처 provenance가 바뀌면 기존 Gate 1~3 QA를 다시 수행한다.

### 2.2 학습 점수와 평가 점수를 분리

답을 먼저 본 뒤 맞힌 것과 무힌트로 맞힌 것을 동일하게 평가하지 않는다.

관리 지표:

- `Learning Score`: 도움을 포함한 학습 진행도
- `Mastery Score`: 무힌트 숙달도
- `Retention Score`: 지연 후 기억 유지도
- `Transfer Score`: 유사/변형 문제 대응도
- `Exam Readiness`: 실전 준비도

### 2.3 미측정을 0점으로 처리하지 않음

- 풀이 데이터가 없는 단원은 `0`이 아니라 `미측정`으로 표시한다.
- 숙달도에는 측정 신뢰도/커버리지를 함께 표시한다.
- 적은 문항으로 나온 높은 점수를 과도하게 확정하지 않는다.

### 2.4 정답률만으로 취약도를 판단하지 않음

다음 신호를 독립적으로 기록한다.

- 정오
- 확신도: 확실 / 애매 / 모름
- 반응시간
- 반복오답
- 확실오답
- 최근 변화
- 마지막 학습 시점
- 힌트 사용 여부
- 지연 재시험 결과
- 변형문제 결과

### 2.5 같은 점수라도 원인에 따라 다른 처방

동일한 55점이라도 다음은 다른 상태다.

- 처음 배우는 55점 → 입력/답치기
- 반복 후 55점 → 오개념/정체 분석
- 과거 90점에서 55점 → 망각/간격복습
- 정답률은 비슷하지만 매우 느림 → 속도훈련
- 확실오답이 많음 → 오개념 즉시 교정
- 연습은 높지만 CBT만 낮음 → 시험전이 훈련

### 2.6 AI는 최소 개입을 기본으로 함

AI가 사용자의 자발적 인출을 방해하지 않도록 개입 단계를 둔다.

`침묵 → 짧은 단서 → 핵심어 힌트 → 개념 비교 → 풀이 1단계 → 전체 설명`

가능하면 가장 적은 도움으로 사용자가 스스로 회상하게 한다.

### 2.7 심리 상태는 진단이 아니라 학습 조건 조정에만 사용

선택적으로 집중도/피로/긴장 상태를 받을 수 있으나 의학적·심리적 진단을 하지 않는다.

상태 정보는 다음 조정에만 사용한다.

- 세션 길이
- 신규/복습 비율
- 시간압박 수준
- 난이도
- 문제 믹스

## 3. QTimer의 12개 핵심 엔진

1. **Verified Question Bank** — 검증된 973문항
2. **Question Classification Engine** — 최신성·반복도·난이도·문제유형
3. **Knowledge Graph** — 과목·단원·개념·선행관계
4. **Dapchigi Engine** — 답치기/정답 패턴 입력
5. **Retrieval Engine** — 인출·빈칸·예측
6. **Adaptive Assistance Engine** — 힌트/지원의 점진적 제거
7. **Weakness Diagnosis Engine** — 취약 원인 분석
8. **Mastery & Retention Engine** — 숙달·유지·전이 측정
9. **Exam Simulation Engine** — 단원/범위/100문항 CBT
10. **Learning Analytics Engine** — 단원 그래프·과락·우선순위
11. **Adaptive Roadmap Engine** — 다음 학습 자동 결정
12. **Personal Learning Experiment Engine** — 사용자별 효과적인 학습법 탐색

## 4. 답치기(Dapchigi) 설계

### 4.1 문제 표시 스타일

- 일반(기본)
- 전체 볼드
- 핵심어 볼드
- 전체 형광펜
- 핵심어 형광펜

기본 색상 예: 문제 파랑 계열.

자동 강조 후보:

- 옳은 / 옳지 않은
- 맞는 / 틀린 / 아닌
- 모두 / 가장
- 최소 / 최대
- 먼저 / 순서
- 개수 / 결과 / 출력

자동 강조는 사용자 수정/해제가 가능해야 한다.

### 4.2 답 표시 스타일

- 일반(기본)
- 전체 볼드
- 핵심어 볼드
- 전체 형광펜
- 핵심어 형광펜
- 답 마킹

기본 색상 예: 답 빨강 계열.

#### 맞는 것을 찾는 문제

정답 선택지의 핵심 또는 전체를 빈칸/형광펜 마킹하여 회상을 유도한다.

#### 틀린 것을 찾는 문제

잘못된 진술의 핵심을 빈칸/형광펜으로 표시하여 잘못된 개념 자체를 구별하도록 한다.

### 4.3 1회독 기본 상태 흐름

초고속 답치기 모드의 기본 흐름:

`답 보기 → Space → 답 가리기 → 문제 보기 → 읽기/예측 → Space → 정답 위치/빈칸 마킹 → Space → 답 공개 → 맞음/애매/틀림 기록`

권장 단축키:

- `Space`: 단계 전환
- `O` 또는 `1`: 맞음
- `A` 또는 `2`: 애매
- `X` 또는 `3`: 틀림

### 4.4 답치기를 유일한 1회독 방식으로 사용하지 않음

사용자 지식상태에 따라 첫 노출 방식을 바꾼다.

- 완전 미학습/초단기 입력 필요 → 답 선노출
- 약간 알고 있음 → 3~5초 예측 후 답 공개
- 중간 숙달 → 문제 먼저, 회상 후 답 확인
- 높은 숙달 → 무힌트 평가

## 5. 회독·숙달 학습 루프

기본 사용자 관점의 5단 구조:

1. **1회독** — 답치기/예측/입력
2. **2회독** — 애매·틀림·모름·확실오답 압축
3. **3회독** — 단원 무힌트 모의고사
4. **4회독** — 모의고사 오답 재시험
5. **5회독 이상** — 단원시험 ↔ 오답 재시험을 안정화될 때까지 반복

단, 실제 엔진은 고정 회독 수보다 숙달 상태를 우선한다.

### 5.1 Assistance Fading

`Level 0 답+핵심어+해설`
→ `Level 1 답+핵심어`
→ `Level 2 정답 빈칸`
→ `Level 3 핵심어만`
→ `Level 4 문제만`
→ `Level 5 변형문제`
→ `Level 6 실전 제한시간`

사용자가 성장할수록 도움을 제거한다.

### 5.2 숙달 판정

`100점 1회`만으로 숙달 처리하지 않는다.

숙달 후보 조건:

- 무힌트 정답률 충분
- 애매 비율 낮음
- 확실오답 없음
- 목표시간 내 안정적 반응
- 지연 재시험 통과
- 필요한 경우 변형문제 통과

## 6. 문제 특성 모델

문제마다 학습용 메타데이터를 둔다.

### 6.1 출제 유형

예시:

- 정의/용어
- 옳은/틀린 설명
- 특징 비교
- 순서/절차
- 조합형
- 코드 실행
- SQL 실행
- 계산/알고리즘
- 표/그림/관계
- 보안/프로토콜
- 최신 기술/표준
- 함정/유사개념

### 6.2 반복 출제도

- `R0`: 단발성
- `R1`: 동일 개념 존재
- `R2`: 반복 개념
- `R3`: 반복 출제 패턴
- `R4`: 거의 같은 문제/선지 변형
- `R5`: 매우 빈번한 핵심 테마

반복 판정은 세 층으로 구분한다.

- Exact Repeat
- Pattern Repeat
- Concept Repeat

### 6.3 난이도

초기 추정:

- `D1`: 단순 암기
- `D2`: 구분/이해
- `D3`: 응용
- `D4`: 계산/코드/SQL 실행
- `D5`: 복합 추론

장기적으로는 사용자의 실제 정답률·시간·확신·반복오답으로 개인 난이도를 보정한다.

### 6.4 최신성 및 출처 신뢰도

최신 출제정보는 신뢰도를 함께 저장한다.

예시:

- `S`: 공식 출제기준
- `A`: 검증 교재/복수 자료 일치
- `B`: 단일 복원자료
- `C`: 비공식 수험자 복원
- `I`: AI 추론

최신성 점수는 공식 출제확률이라고 표현하지 않고 **학습 우선순위용 내부 지표**로 표시한다.

## 7. 사용자 지식·심리 상태 모델

### 7.1 확신-정확도 매트릭스

| 확신 | 정답 | 오답 |
|---|---|---|
| 확실 | 숙달 후보 | **확실오답 / 오개념 고위험** |
| 애매 | 불안정 지식 | 취약 |
| 모름 | 특수/추측 확인 | 미학습 |

확실오답은 즉시 교정 → 짧은 지연 재출제 → 다음날/후속 세션 재출제로 특별 처리한다.

### 7.2 맞았지만 애매/느린 문제도 취약에 포함

- 정답 + 애매
- 정답 + 매우 느림
- 정답 + 반복적으로 힌트 사용

은 단순 정답과 분리한다.

### 7.3 오류 원인 분류

반복오답/확실오답 등 고위험 문제에서만 빠르게 묻는다.

- 개념 모름
- 두 선택지 혼동
- 문제 잘못 읽음
- 계산/실행 실수
- 기억 안 남
- 시간 부족
- 확실하게 잘못 알고 있었음

매 문제마다 원인 입력을 강제하지 않는다.

### 7.4 사용자 학습 패턴 추정

예시:

- 지식부족형
- 과신형
- 저신뢰형
- 느린정답형
- 실수형
- 망각형
- 시험취약형
- 특정유형 취약형

이는 의료·성격 진단이 아니라 QTimer 내부 학습 처방용 패턴이다.

## 8. 점수·상황별 적응 정책

아래 구간은 **공식 합격선이 아니라 QTimer 내부 학습 제어 기준**이다.

| 숙달도 | 상태 | 기본 처방 |
|---:|---|---|
| 미측정 | 진단 전 | 5~10문항 진단 |
| 0~39 | 기초 형성 | 답치기·설명·Worked Example |
| 40~59 | 불완전 학습 | 예측→답→빈칸회상 |
| 60~74 | 불안정 | 취약 + 유사개념 변별 |
| 75~84 | 안정화 | 무힌트 단원시험 |
| 85~94 | 숙달 | 간격복습 + 혼합출제 |
| 95~100 | 과잉학습 후보 | 일시 제외 후 지연시험 |

같은 점수라도 다음 요인으로 처방을 수정한다.

- 첫 학습인지 반복학습인지
- 과거 최고점 대비 하락인지
- 확실오답 비율
- 애매 비율
- 평균 반응시간
- 지연 유지율
- CBT 성적과 학습모드 성적 차이
- 사용자 선택 상태(피로/집중/긴장)

## 9. 학습 우선순위와 ROI

`출제 중요도`와 `사용자 취약도`를 분리한 뒤 결합한다.

초기 우선순위 모델 예시:

- 반복 출제도
- 최신성
- 출제기준 중요도
- 사용자 숙달 부족분
- 확실오답/반복오답
- 난이도
- 과목 과락 위험
- 전체 범위 커버리지 부족

시험 직전의 최적화 순서는 다음을 기본으로 한다.

`과락 방지 → 합격 안정권 → 고빈출 취약 제거 → 고득점`

### 9.1 학습 ROI

개념적으로 다음을 추정한다.

`학습 ROI = 예상 득점/숙달 개선량 ÷ 예상 학습시간`

이는 확정적 점수 예측이 아니라 **학습 순서를 고르는 내부 휴리스틱**으로 사용한다.

## 10. 분석 대시보드

사용자에게는 내부 모델을 모두 노출하지 않고 핵심 행동정보를 보여준다.

### 10.1 상단 요약

- 현재 시험준비도
- 과락 위험 과목
- 오늘의 최우선 단원
- 추천 학습량
- `오늘 추천학습 시작` 버튼

### 10.2 과목별 안정도

예:

`1과목 82 안정 / 2과목 76 안정 / 3과목 61 보완 / 4과목 52 위험 / 5과목 74 보완`

### 10.3 단원별 숙달도 그래프

- 미측정은 점수 0으로 표시하지 않는다.
- 숙달도와 측정신뢰도를 함께 제공한다.
- 목표선은 QTimer 내부 학습 기준임을 표시한다.

### 10.4 출제 중요도 × 나의 취약도

오른쪽 위 영역(중요 + 취약)을 먼저 학습한다.

### 10.5 회독 성장곡선

회독/날짜별 다음을 추적한다.

- 숙달도
- 지연 유지도
- 평균 반응시간
- 확실오답 수
- 취약문제 수

정체(plateau) 시 문제 수를 단순 증가시키지 않고 원인 분석/학습법 변경을 권장한다.

### 10.6 설명 가능한 추천

추천은 이유를 함께 표시한다.

예:

> 4과목 Ch02를 먼저 학습하세요. 숙달도 48, 목표 대비 27 부족, 반복출제 중요도 높음, 코드 실행형 정답률 낮음, 확실오답 5문제입니다.

그리고 바로 `추천 문제 시작`으로 연결한다.

## 11. 범위 선택·모의고사

사용자가 다음 범위를 조합할 수 있다.

- 과목
- Chapter
- 문제 유형
- 최신 유형
- 고빈출
- 난이도
- 취약/오답/애매/미풀이

문항 수:

- 전체
- 10 / 20 / 40 / 60 / 100
- 직접 입력

출제 정책:

- 순서
- 랜덤
- 취약 우선
- 오답 우선
- 미풀이 우선
- 빈출 강화
- 최신 유형 강화
- 고난도 강화
- 실전 균형
- 적응형

실전 100문항 모드는 시험 구조에 맞는 과목별 균형을 유지하는 별도 정책을 사용한다.

## 12. Adaptive Roadmap

입력:

- 시험일
- 하루 학습 가능시간
- 목표 수준
- 현재 숙달도
- 과목별 위험
- 최근 성장률
- 지연 유지도
- 출제 중요도

출력:

- 오늘 해야 할 단원
- 문제 수
- 학습 방식
- 예상 소요시간
- 이후 재평가 시점

로드맵은 고정 계획표가 아니라 학습결과에 따라 재계산된다.

안전장치:

1. 과락 위험 과목 방치 금지
2. 전체 출제범위 최소 커버리지 유지
3. 빈출/취약 우선
4. 이미 숙달한 영역의 과잉반복 제한

## 13. Personal Learning Experiment Engine

사용자에게 어떤 학습법이 실제로 잘 맞는지 지연 재시험으로 비교한다.

예:

- A군: 답치기
- B군: 예측 후 정답
- C군: 빈칸 회상

직후 점수보다 1~3일 후 무힌트 Retention/Transfer를 우선 평가한다.

충분한 데이터가 쌓이면 사용자의 학습 정책 가중치를 조정한다.

## 14. Knowledge Graph

문제가 반복해서 틀릴 때 표면 Chapter만 반복하지 않고 선행개념을 탐색한다.

예:

`함수 종속 → 정규화 → 이상현상 → 정규형 판별`

정규형 판별을 반복오답하면서 함수 종속 지식이 부족하다면 선행개념부터 복구한다.

초기 버전은 수동/규칙 기반 concept tag와 prerequisite 관계로 시작하고, 이후 확장한다.

## 15. 피드백 정책

목적에 따라 피드백 시점을 바꾼다.

- 입문/오개념 교정 → 즉시 정답 + 짧은 설명
- 답치기 → 즉시 피드백
- 취약교정 → 즉시 피드백 + 비교개념
- 단원시험 → 문제별 답 공개 최소화, 시험 종료 후 검토 가능
- 실전 CBT → 전체 종료 후 일괄 채점/해설

## 16. Interleaving 정책

무조건 랜덤 혼합하지 않는다.

초기 규칙 예:

- 숙달 < 60 → 단원 집중(Blocked)
- 60~74 → 유사개념 혼합
- 75~89 → 과목 내 혼합
- 90 이상 → 과목간 실전 혼합

향후 실제 사용자 Retention/Transfer 데이터로 정책을 검증한다.

## 17. 피로·정체 감지

### 17.1 정체

여러 회독에서 점수 변화가 거의 없고 특정 유형이 지속적으로 낮으면 해당 유형만 분리해 학습방법을 변경한다.

### 17.2 피로/집중저하 가능성

최근 문제에서 다음이 동시에 증가하면 경고 후보로 본다.

- 반응시간
- 쉬운 문제 오답
- 애매
- 연속오답

이는 심리 진단이 아니라 세션 품질 신호다.

대응:

- 신규 고난도 비율 감소
- 짧은 복습 전환
- 세션 종료 권장
- 시간압박 완화

## 18. 사용자 UX 원칙

내부 분석은 복잡해도 사용자에게는 네 가지를 우선 보여준다.

1. **현재 상태** — 어디가 위험한가
2. **원인** — 왜 낮은가
3. **중요성** — 시험 관점에서 왜 먼저 해야 하는가
4. **행동** — 지금 몇 문제를 어떤 방식으로 풀 것인가

예:

> 4과목 Ch02 숙달도 54 / 불안정. C 포인터·구조체의 반복오답과 확실오답이 주원인입니다. 반복출제 중요도가 높은 영역이므로 답치기 7문제 → 변별 6문제 → 단원시험 10문제를 권장합니다.

버튼:

`[지금 시작]`

## 19. 데이터·신뢰성 원칙

- 공식 합격 기준과 QTimer 내부 숙달 기준을 UI에서 명확히 구분한다.
- 최신성/빈출도는 출처 신뢰도와 함께 표시한다.
- 점수에는 측정문항수/커버리지/신뢰도를 함께 관리한다.
- 적은 데이터로 개인 성향이나 능력을 단정하지 않는다.
- AI 추천은 설명 가능한 근거를 제공한다.
- 자동 추천보다 사용자의 수동 범위 선택을 항상 허용한다.
- 사용자 학습기록의 원본 Attempt는 append-only로 보존한다.

## 21. 완료/검증 기준

기능의 성공 여부는 화면 동작만으로 판단하지 않는다.

### 제품 QA

- 기존 973문항 Gate 1~3 유지
- 브라우저 E2E
- 저장/복원
- 시험모드 상태 일관성
- 범위 선택 정확성

### 학습 QA

- 도움을 받은 정답이 무힌트 숙달로 과대평가되지 않는가
- 미측정을 0점으로 잘못 표시하지 않는가
- 확실오답이 우선 교정되는가
- 숙달한 문제의 과잉반복이 줄어드는가
- 지연 재시험에서 Retention을 별도로 측정하는가
- 변형문제를 SOURCE BANK와 혼동하지 않는가
- 추천 이유를 사용자가 이해할 수 있는가

## 23. 최종 제품 원칙

QTimer는 사용자를 더 오래 붙잡아 두는 시스템이 아니라 **필요한 학습량을 줄이고, 실제 시험에서 틀릴 가능성이 높은 내용을 먼저 제거하는 시스템**이어야 한다.

최종 핵심 문장:

> 많이 푸는 앱이 아니라, 시험에 중요한 문제와 내가 틀릴 가능성이 높은 문제를 찾아 가장 적절한 학습 방식으로 처방하고, 그 효과를 지연 재평가하는 시스템.
