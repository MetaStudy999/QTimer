# QTimer UI/UX Spec

## 1. 핵심 원칙

사용자가 실제로 익혀야 하는 화면은 두 종류로 제한한다.

- 학습할 때는 오른쪽에 해설
- 시험처럼 풀 때는 오른쪽에 답안표

답과 상태는 색상만으로 구분하지 않고 아이콘/텍스트도 함께 사용한다.

## 2. Learn Workspace

PC 기본 구조:

`왼쪽 문제 | 오른쪽 결과/해설`

### 왼쪽
- 시험 / 교재 / 과목 / 단원
- 현재 세션 위치 + 원문제번호 + 페이지
- 문제 본문
- 선택지 또는 빈칸 입력
- 문제별 타이머
- 목표시간
- 애매 표시
- 제출 / 다음

### 오른쪽
답 제출 전:
- 해설 숨김

답 제출 후:
- 정답/오답
- 내 답 / 최종 채점 정답
- elapsed time
- IN / OVER
- confidence

탭:
- 핵심
- 문제집 해설
- AI 해설
- 내 메모

핵심 탭 기본 내용:
- keyword
- one-line summary
- discrimination point
- FINAL KEY

## 3. Exam Workspace

PC 기본 구조:

`왼쪽 문제 | 오른쪽 전체 답안표`

### 왼쪽
- 문제 본문
- 선택지
- 애매 표시
- 이전/다음

### 오른쪽
- 전체 답안표
- 선택답
- 미응답
- 애매
- 현재 문제 강조

왼쪽 선택지와 오른쪽 답안표는 동일한 상태를 공유한다.

예:
- 왼쪽에서 ③ 선택 → 오른쪽 37번도 ③ 표시
- 오른쪽에서 ④ 선택 → 왼쪽 문제 선택도 ④로 변경

## 4. 문제풀이 vs 모의고사

### 문제풀이
- Exam Workspace 사용
- 즉시채점 / 전체 후채점 선택 가능
- 필요시 문제별 시간 기록

### 모의고사
- Exam Workspace 사용
- 제출 전 정답/오답/해설 공개 금지
- 전체 시험시간만 표시
- 미응답/애매 문제 필터
- 제출 후 전체 채점과 과목별 분석

## 5. 답안/상태 표시

상태 예:
- ✅ 정답
- ❌ 오답
- △ 애매
- ? 모름
- ⏱ OVER / TIME OUT
- 미응답

형광펜/배경 강조는 사용자 설정을 따른다.

## 6. 표시 스타일 설정

사용자가 설정 가능:

### 글자
- 문제 글꼴
- 선택지 글꼴
- 해설 글꼴
- 크기
- 굵기
- 줄 간격
- 자간

### 강조
- 선택한 답
- 정답
- 오답
- 애매
- 핵심어
- FINAL KEY

### 형광펜 방식
- 배경형
- 밑줄형

### 프리셋
- 기본
- 형광펜 학습
- 고대비
- 눈 편한 모드
- 야간 모드

## 7. 타이머 UI

정책:
- No Limit
- Soft Limit
- Hard Limit

Hard Limit 기본 흐름:

`제한시간 도달 → TIME OUT → 짧은 피드백 → 다음 문제 자동 이동`

자동 이동 지연 옵션:
- 즉시
- 0.5초
- 1초

시간초과 상태와 정오 상태는 별도로 보여준다.

## 8. 정답 검증 UI

문제 화면에 작은 액션 제공:

`⚑ 문제/정답 이상`

신고 유형:
- 문제 인식 오류
- 선택지 인식 오류
- 정답 인식 오류
- 문제집 정답 오류 의심
- 해설 오류
- 기타

검증 화면에서는:
- 원본 문제/정답 이미지
- source_answer
- ai_detected_answer
- ai_reasoned_answer
- 사용자 선택
- 검증 메모

를 함께 보여준다.

정상 일치 문제는 사용자가 매번 검증하지 않도록 한다.

## 9. 빈칸 문제 UI

왼쪽:
- 문장/개념
- 빈칸 입력
- 힌트
- 제출

오른쪽 제출 후:
- 대표 정답
- 허용 답안 여부
- 핵심
- 문제집 해설
- AI 해설
- 메모

힌트 사용 여부는 기록한다.

## 10. 모바일

### Learn
좌우 2열 대신:
- 문제
- 결과/해설
- 메모

탭/아코디언 방식으로 전환한다.

### Exam
- 문제 중심
- 답안표는 펼치기/바텀시트 스타일로 접근

기능은 PC와 동일하고 배치만 반응형으로 바꾼다.

## 11. 키보드 우선

권장 단축키:
- SPACE: 타이머 시작/종료(텍스트 입력 포커스에서는 정상 공백)
- 1~9: 답 선택
- A: 애매
- M: 모름
- Enter: 확정/다음
- P: 일시정지
- Ctrl+Z: 직전 Attempt 취소/되돌리기
- Esc: 입력/다이얼로그 종료

입력 필드에 포커스가 있을 때 전역 단축키가 방해하지 않도록 한다.
