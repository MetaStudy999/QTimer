# QTimer v0.1 Product Spec

기준일: 2026-08-11
상태: 구현 기준 문서

## 1. 목표

QTimer v0.1은 기출문제를 빠르게 풀고, 풀이시간·정오·확신도를 기록하여 취약문제를 자동 압축하고 반복하는 시험 대비 도구다.

v0.1 성공 기준은 기능 수가 아니라 다음이다.

> 문제를 넣으면 즉시 풀 수 있고, 자동채점되며, 오답·모름·애매·시간초과 문제를 다시 훈련할 수 있다.

## 2. P0 기능

### 문제 데이터
- 시험 / 교재 / 과목 / 목차 트리 / 원문제번호 / 페이지
- 문제유형
- 문제 본문 및 선택지
- 정답
- 문제집 해설
- AI 해설
- 사용자 메모
- 원본 이미지 링크
- AI/OCR 추출 상태

### Learn Workspace
- 왼쪽 문제
- 오른쪽 결과/해설/메모
- 답 제출 전 해설 숨김
- 답 제출 후 정오·확신·시간 상태 표시
- 핵심 / 문제집 해설 / AI 해설 / 내 메모 탭

### Exam Workspace
- 왼쪽 문제
- 오른쪽 전체 답안표
- 문제 선택지와 답안표 양방향 동기화
- 미응답 / 애매 표시
- 문제 이동
- 모의고사는 제출 전 정답·해설 비공개

### 타이머
- No Limit
- Soft Limit
- Hard Limit
- 문제 유형 또는 세션별 목표시간 설정
- Hard Limit에서 TIME OUT 후 자동 다음 문제
- 자동 이동 지연 설정
- 시간초과와 정오 상태 분리

### 취약 Queue
자동 포함 대상:
- 반복오답
- 확실오답
- 모름
- 오답
- 애매
- TIME OUT / OVER

### 진행상태
- 미풀이
- 최소 1회 풀이
- 오답
- 모름
- 애매
- 느림
- 숙달
- 과목별 위험도

### 정답 검증
- source_answer
- ai_detected_answer
- ai_reasoned_answer
- user_verified_answer
- effective_answer
- 검증 Queue
- 원본 보기
- 문제/정답 이상 신고
- 정답 변경 이력
- 변경 후 과거 Attempt 재채점

### 빈칸 문제
- cloze 문제 유형
- 대표 정답 + 허용답안
- 힌트 사용 여부
- 취약개념에 제한적으로 생성

### 표시 스타일
- 글꼴
- 글자 크기/굵기
- 줄 간격/자간
- 선택답/정답/오답/애매/핵심어/FINAL KEY 강조색
- 배경형/밑줄형 형광펜
- 프리셋

## 3. 모드별 동작

### 빠른 회독
- 기본 Hard Limit

- 목적: 전체 범위 분류와 취약 수집

### 학습

- 문제집 해설 / AI 해설 / 메모
- 필요시 빈칸 및 변형문제

### 문제풀이
- Exam Workspace 사용
- 즉시채점 또는 전체 후채점 선택 가능
- 답안표 사용

### CBT 모의고사
- Exam Workspace 사용
- 제출 전 정답/오답/해설 공개 금지

### 취약 집중
- 취약 Queue만 출제
- 우선순위 기반 반복
- 숙달 시 Queue에서 제외 가능

## 4. 문제 개수

단원별 문제 수는 고정하지 않는다.

- 단원 문제 수 = 해당 단원에 연결된 Question 수
- 상위 과목/장 진행률 = 실제 문항 수를 기준으로 가중 집계
- `1차 풀이 완료`와 `숙달 진행`은 별도 표시

## 5. 문제번호

원문제번호는 변경하지 않는다.

예:

`취약훈련 7/32 · 원문제 384번 · p.217`

내부 식별자는 UUID를 사용하며 원문제번호를 전역 ID로 사용하지 않는다.

## 6. 숙달 기본 규칙

`2회 연속 정답 + 두 번 모두 확실 + 두 번 모두 목표시간 이내`

위 조건을 만족하면 MASTERED 후보로 처리한다.

애매 정답, 힌트 사용 빈칸 정답, 시간초과 정답은 숙달 조건을 만족하지 않는다.

## 7. v0.1 제외

다음은 v0.1 필수 구현에서 제외한다.

- 커뮤니티 / 랭킹
- 고급 시각화 차트
- 마켓플레이스
- 실시간 협업
- 복잡한 추천 알고리즘
- 대규모 OCR 고도화
- 완전 자동 AI API 운영
- PDF 전체 자동 문제은행화

데이터 모델은 이후 확장을 막지 않도록 설계한다.
