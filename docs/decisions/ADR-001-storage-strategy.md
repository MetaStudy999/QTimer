# ADR-001: Google Workspace 중심 초기 저장 전략

상태: Accepted
날짜: 2026-08-11

## Context

QTimer는 시험 직전 빠르게 사용할 수 있어야 하며, 문제/정답/해설 데이터를 사용자가 직접 확인하고 수정할 수 있어야 한다.

완전한 운영 DB와 복잡한 백엔드를 먼저 구축하면 학습 투입이 늦어진다.

## Decision

초기 운영에서는 역할을 다음처럼 분리한다.

- Google Drive: 원본 문제/정답 이미지
- Google Sheets: 구조화 문제은행, 정답, Attempt, Progress, 검증 Queue
- Google Docs: 사람이 읽는 취약문제 해설집
- 브라우저 로컬 저장: 타이머/현재 세션/오프라인 즉시 기록

Supabase/PostgreSQL은 서비스 규모 확대 또는 다중 사용자 운영 시점에 도입할 수 있도록 데이터 모델 호환성을 유지한다.

## Why

- 시험 전 구축시간을 줄일 수 있다.
- 사용자가 데이터를 직접 검토/교정하기 쉽다.
- 정답표와 대량 문제 데이터를 Sheets에서 빠르게 확인할 수 있다.
- AI 해설을 Docs 형태로 읽기 좋게 유지할 수 있다.
- 원본 사진과 구조화 데이터를 분리할 수 있다.

## Consequences

- Sheets를 매 문제 타이머의 실시간 저장 대상으로 사용하지 않는다.
- 로컬에서 즉시 저장 후 묶어서 동기화한다.
- Docs를 운영 DB처럼 사용하지 않는다.
- 장기적으로 데이터 규모/동시사용자가 커지면 DB 이전이 필요할 수 있다.
