# QTimer 정답 위험군 독립 검증 로그

업데이트: 2026-08-11

## 기준

- 문제은행 baseline: 973문항
- 원본 하단 정답을 보존한다.
- 고위험 문항은 원본 문제/보기/하단 정답과 독립 풀이를 함께 대조한다.
- 구조화 누락은 quality override에서 보완하고 원본 provenance를 유지한다.
- 교재 정답과 표준 규격 해석이 충돌할 여지가 있으면 정답을 임의 변경하지 않고 경고를 남긴다.
- 위험군은 실제 실행·계산이 필요한 문제를 우선하며 단순 언어/알고리즘 용어 문제는 실행 위험군에서 제외한다.

## 위험도 분류기 정제

- 언어 이름, 키워드, 연산자 우선순위, `main()` 등 단순 개념형은 `코드 실행`에서 제외한다.
- 실제 코드 조각과 실행/출력/값 계산 문맥이 함께 있을 때만 `코드 실행` 위험으로 분류한다.
- COCOMO·PERT·LRU 등의 용어가 등장하는 것만으로 계산 위험으로 분류하지 않는다.
- 수치, 참조열, 프레임, 요청 큐, 메모리 크기, 일정 경로 등 실제 추적/계산 정보가 있을 때 계산 위험으로 분류한다.
