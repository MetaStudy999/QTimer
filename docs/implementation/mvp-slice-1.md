# QTimer v0.1 MVP Slice 1

기준일: 2026-08-11

## 목적

수제비 2026 정보처리기사 필기 사진을 실제 QTimer 데이터로 변환하여, 시험 전 즉시 속도훈련을 시작할 수 있는 최소 동작 버전이다.

## 포함 범위

- 01_소프트웨어설계 샘플 10문항(원문제 13~22)
- Drive 원본 이미지 링크
- 단일선택 객관식
- 빠른 회독 / 학습 / 취약 집중
- Hard / Soft / No Limit
- Hard Limit TIME OUT 자동 다음 문제
- 정오 / 확신 / 시간 3축 기록
- 애매 / 모름 독립 상태
- 취약문제 자동 집계
- 사용자 정답 검증 및 최종 정답 override
- 최종 정답 변경 시 과거 Attempt 재채점
- 문제/정답 이상 플래그
- localStorage 기반 브라우저 로컬 보존
- 키보드 단축키

## 아직 미포함

- 전체 교재 자동 변환
- Google Sheets 동기화
- Google Drive 폴더 자동 감시
- AI API 자동 호출
- Exam Workspace / 전체 답안표
- CBT 모의고사
- 빈칸/변형문제 자동 생성
- 표시 프로필 세부 설정

## 검증 대상

1. 문제 번호와 선택지 구조가 사진과 일치하는가
2. Hard Limit에서 시간초과가 오답과 분리되어 기록되는가
3. 정답·애매·OVER 복합 상태가 동시에 보존되는가
4. 사용자가 최종 정답을 수정할 수 있는가
5. 수정한 정답으로 기존 풀이가 재채점되는가
6. 취약 집중 모드가 오답/애매/모름/OVER를 재출제하는가
