# QTimer 검증된 반복 문제문

업데이트: 2026-08-11

## 목적

심층 QA에서 `questionText`가 완전히 동일한 문제를 자동 검출하되, 수제비 원본에 실제로 반복 수록된 문제를 데이터 오류로 잘못 삭제하지 않기 위한 검증 기록이다.

판정 원칙:

1. 문제번호와 원본 페이지가 다르면 별도 원본 문제로 취급한다.
2. 같은 문제문이라도 선택지가 다르면 별도 문제로 유지한다.
3. 문제문·선택지까지 동일하더라도 원본의 서로 다른 페이지에 실제 재수록된 것이 확인되면 유지한다.
4. 아래 목록에 없는 새 동일 문제문은 다시 수동 검토 큐로 보낸다.

## QA 동작

`scripts/qa-question-bank.mjs`의 `VERIFIED_REPEATED_STEM_PAIRS`에 위 14쌍을 등록한다.

정상 기대값:

```text
exact repeated question-stem pairs : 14
verified source-book repeated stems : 14
unverified repeated stems : 0
review queue items : 0
```

앞으로 새 동일 문제문이 추가되어 allowlist에 없는 경우에만 `Manual review queue`에 표시한다.
