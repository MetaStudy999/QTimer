# QTimer Dapchigi Focus Reading v2

기준일: 2026-08-12

## 1. 목적

답치기를 일반 웹앱 화면이 아니라 **문제 회상과 해설 확인에만 집중하는 학습 화면**으로 만든다.

핵심 문장:

> 범위를 정한 뒤에는 문제, 해설, 현재 위치, O/A/X 외에는 최대한 보이지 않게 한다.

## 2. 데스크톱 레이아웃

```text
Study Context Bar
┌──────────────────────────────────────┬──────────────────────────┐
│                문제                  │           해설           │
│                                      │                          │
│ 전체 문장: 연한 형광 배경            │ reveal 전: 해설 잠금      │
│ 핵심어: 진한 형광 + 흰색 글자        │ reveal 후:                │
│                                      │ - 정답                    │
│ 선택지                               │ - 핵심 finalKey           │
│                                      │ - 문제집 해설             │
└──────────────────────────────────────┴──────────────────────────┘
       Space 진행 | O 맞음 | A 애매 | X 틀림
```

문제 영역이 해설보다 넓다. 기본 비율은 약 2:1이며 큰 화면에서도 전체 shell 폭은 제한한다.

1080px 이하에서는 1열로 바꾸어 해설이 문제 아래에 배치된다.

## 3. 문제 강조

### 전체 문장

- 연한 형광색 배경
- 기존 Settings v3의 **문제 형광펜 색상(`--qt-q-highlight`)을 그대로 사용**한다.
- 사용자가 `집중 블루`, `안정 민트`, `기억 옐로우`, `저자극 라벤더`, `고대비 그레이` 또는 사용자 지정 색상을 선택하면 Focus Reading도 즉시 같은 연한 색을 사용한다.
- 기존 `형광펜 + 볼드` 계약을 유지한다.
- 사용자 글자색/폰트 설정은 유지한다.

### 핵심어

- 현재 문제 형광펜 색상을 기준으로 **같은 계열의 더 어두운 색을 자동 파생**한다.
- 흰색 글자
- 높은 font-weight(900)
- 최대 약 6개로 제한하여 모든 단어가 강조되는 것을 방지한다.

색상 계층은 다음처럼 동작한다.

```text
Settings v3 문제 형광펜 색상
        ↓
전체 문제 = 원래 연한 색
        ↓
핵심어 = 같은 색 + dark neutral 혼합
        ↓
흰색 글자 + 900 bold
```

고정된 노랑/갈색을 강제하지 않는다. 사용자가 선택한 학습 테마와 Focus Reading의 강조 체계를 하나의 색상 계층으로 유지한다.

### 정답 누설 방지

핵심어는 `finalKey`, 정답 선택지, 해설에서 가져오지 않는다.

오직 **현재 문제 문장에 이미 존재하는 표현**에서 추출한다.

우선순위:

1. `옳지 않은`, `틀린`, `아닌 것`, `해당하지 않는` 등 조건 반전 표현
2. 괄호 안 기술 용어
3. 영문 약어/전문 용어
4. 문제 문장의 비교적 긴 핵심 명사

따라서 강조 자체가 정답 힌트가 되는 것을 최소화한다.

## 4. 해설 패널의 단계별 공개

해설 패널은 항상 같은 위치를 차지해 레이아웃 이동을 막는다.

```text
preview  답 보기      -> 해설 잠금
question 문제 회상    -> 해설 잠금
mark     빈칸 마킹    -> 해설 잠금
reveal   정답 확인    -> 해설 공개
```

preview에서 답은 보이지만 해설까지 읽게 하지 않는다. 답을 먼저 인코딩한 뒤 문제를 회상하고 마지막에 설명을 연결하기 위함이다.

reveal에서만 다음을 표시한다.

- 유효 정답 번호와 선택지
- `finalKey`
- `sourceExplanation`

AI가 새 해설을 생성해 원본 문제집 해설과 섞지 않는다.

## 5. 메뉴 최소화

Focus Reading 활성 시 숨긴다.

- 일반 App Header
- 대시보드/학습/환경설정/백업 등 전역 메뉴
- 일반 Study control bar
- 세션 summary
- 답치기 범위/스타일 제어 패널(범위 적용 후)

유지한다.

- Study Context Bar
- 문제
- 해설
- Bottom Action Dock

필요한 제어만 Context Bar에 둔다.

- `범위·표시 ⚙`: 답치기 설정 패널 임시 열기
- `집중 종료 Esc`: 학습 상태를 훼손하지 않고 대시보드로 복귀

설정 패널은 범위를 적용하면 자동으로 닫힌다.

## 6. 기존 의미 마킹과의 관계

Semantic Choice Marking v1은 그대로 유지한다.

- 긍정형: 정답만 빨강 `● 선택`
- 부정형: 정답 빨강 `● 선택`, 나머지 파랑 `✓ 부합`
- 취소선 없음

문제 stem의 연한/진한 형광 강조는 **읽기 구조**이고, 선택지의 빨강/파랑은 **정답 피드백 의미**다. 두 기능을 섞지 않는다.

## 7. 데이터 안전성

변경하지 않는다.

- 973문항 SOURCE BANK
- sourceAnswer / provenance
- 일반 Attempt
- Dapchigi O/A/X Attempt schema
- Settings schema

Focus Reading은 presentation layer만 변경한다.

## 8. 검증 기준

- 답치기 범위 적용 후 App Header와 범위 패널이 시각적으로 숨는가
- Study Context / Bottom Action Dock은 유지되는가
- 문제 전체가 **현재 Settings 문제 형광펜 색상**의 연한 배경인가
- 핵심어가 같은 테마 계열의 진한 배경 + 흰색 글자인가
- 기존 `형광펜 + 볼드` 표시 계약이 유지되는가
- 핵심어가 문제 문장 안에서만 파생되는가
- reveal 전 해설 내용이 노출되지 않는가
- reveal에서 현재 문항의 `finalKey`와 `sourceExplanation`이 표시되는가
- 1080px 이하에서 1열로 안전하게 바뀌는가
- Dashboard 복귀 시 Focus Reading 스타일이 누출되지 않는가
