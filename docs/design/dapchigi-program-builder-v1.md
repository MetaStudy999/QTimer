# QTimer Dapchigi Program Builder v1

## 목적

답치기 순서를 코드 문법이 아니라 **시각적 블록 프로그램**으로 사용자가 직접 구성한다.

기본 답치기는 그대로 유지하며, 사용자가 `프로그램 사용`을 켠 경우에만 사용자 프로그램이 Space/O/A/X 흐름을 제어한다.

## 핵심 UX

집중모드 상단에 `프로그램 ▷` 버튼을 둔다.

편집기는 오른쪽 Drawer로 열리며 문제 화면은 계속 볼 수 있다. 편집기에는 다음만 노출한다.

1. 프로그램 선택
2. `+ 새 프로그램`, 복제, 삭제
3. 프로그램 이름
4. `이 프로그램으로 답치기` On/Off
5. `처음부터 실행`
6. 단계 추가 버튼
7. 드래그 가능한 프로그램 순서
8. 검증 결과와 실제 실행 순서 미리보기

## 제공 블록

| 블록 | 실행 의미 |
|---|---|
| 답 보기 | 정답 카드 우선 표시 |
| 문제 회상 | 정답을 숨기고 문제 회상 |
| 빈칸 마킹 | 회상용 빈칸 표시 |
| 정답 확인 + 해설 | 정답 및 오른쪽 해설 공개 |
| O/A/X 평가 | 정답/해설 공개 상태에서 자기평가 대기 |
| 반복 시작 | 반복 구간 시작. 2~20회 |
| 반복 끝 | 반복 구간 종료 |

## 반복 규칙

`반복 시작 × N`과 `반복 끝` 사이의 실행 블록을 N회 펼쳐서 실행한다.

예:

```text
답 보기
반복 시작 × 2
  문제 회상
  정답 확인 + 해설
반복 끝
O/A/X 평가
```

실제 실행 순서:

```text
답 보기
→ 문제 회상
→ 정답 확인 + 해설
→ 문제 회상
→ 정답 확인 + 해설
→ O/A/X 평가
```

### v1 안전 제한

- 독립 반복 구간은 여러 개 사용할 수 있다.
- **반복 안의 반복은 금지**한다.
- 반복 시작/끝이 맞지 않으면 저장은 허용하되 실행은 차단한다.
- 빈 반복 구간은 실행 차단한다.
- 반복 횟수는 2~20회로 제한한다.
- 원본 블록은 최대 40개, 반복을 펼친 실행 단계는 최대 100개로 제한한다.

이 제한은 드래그 후 발생할 수 있는 구조 오류와 의도하지 않은 무한/과도 반복을 예방한다.

## O/A/X 규칙

- O/A/X 평가 블록은 정확히 1개 필요하다.
- 프로그램의 마지막 블록이어야 한다.
- 반복 구간 안에 넣을 수 없다.
- 평가 단계에 진입하면 정답/해설을 자동 공개한다.
- O/A/X 입력 후 기존 Dapchigi Attempt 기록 로직이 실행되고 다음 문제로 이동한다.
- 다음 문제에서는 같은 프로그램의 첫 블록부터 다시 시작한다.

따라서 사용자 프로그램은 학습 흐름만 정의하며, 평가 기록 스키마를 새로 만들지 않는다.

## 편집 방법

### 단계 추가

단계 추가 버튼을 누르면 프로그램 목록에 블록을 추가한다. 평가 블록이 이미 있으면 일반 학습 블록은 평가 앞에 추가해 마지막 평가 규칙을 최대한 보존한다.

### 순서 변경

- 데스크톱: 블록을 마우스로 Drag & Drop
- 접근성/정밀 조작: 각 블록의 `↑ / ↓`

드래그 결과는 즉시 LocalStorage에 저장한다.

### 프로그램 관리

- 새 프로그램: 안전한 기본 답치기 구조로 생성
- 복제: 현재 프로그램을 복사
- 삭제: 프로그램이 2개 이상일 때만 허용
- 이름: 입력 즉시 저장

## 실행 모델

저장 키:

```text
qtimer-dapchigi-programs-v1
```

개념 스키마:

```json
{
  "version": 1,
  "enabled": false,
  "selectedProgramId": "...",
  "programs": [
    {
      "id": "...",
      "name": "2회 강화",
      "blocks": [
        {"id":"...","type":"preview"},
        {"id":"...","type":"repeat-start","count":2},
        {"id":"...","type":"question"},
        {"id":"...","type":"reveal"},
        {"id":"...","type":"repeat-end"},
        {"id":"...","type":"rate"}
      ]
    }
  ]
}
```

실행 시에는 원본 블록 배열을 변경하지 않고 메모리에서 `compiled steps`를 만든다.

## 기존 답치기와의 호환성

### 프로그램 OFF

기존 Dapchigi v1의 Space 순서가 그대로 동작한다.

```text
preview → question → mark → reveal → O/A/X
```

### 프로그램 ON

Space 입력만 Program Runtime이 우선 처리한다.

- display 블록: `state.dapchigiV1.step`을 지정 단계로 이동
- 평가 블록: reveal 상태로 만들고 O/A/X를 기다림
- O/A/X 기록은 기존 Dapchigi `recordRating` 경로 사용

SOURCE BANK, `state.attempts`, Dapchigi Attempt schema는 변경하지 않는다.

## 집중모드 UI

프로그램 실행 중 Context Bar에는 다음 상태를 작은 chip으로 표시한다.

```text
프로그램 · 2회 강화 · 3/6 · 반복 1/2
```

편집기를 닫으면 학습 화면에는 프로그램 편집 UI가 남지 않는다.

## 백업/복원

전체 QTimer 백업의 `dapchigiPrograms` 필드에 프로그램을 포함한다.

기존 백업처럼 이 필드가 없는 파일도 정상 복원한다.

복원 직전 snapshot에도 답치기 프로그램을 포함해 `복원취소`가 가능하도록 한다.

## QA 기준

Browser E2E에서 다음을 검증한다.

- Program API/저장키 로드
- 새 프로그램 생성 및 이름 저장
- 빠른 템플릿 적용
- 마우스 Drag & Drop 순서 저장
- 반복 ×2 / ×3 컴파일 결과
- 반복 끝 누락 시 실행 차단
- 반복 구조 복구 후 실행 가능
- Space가 프로그램의 compiled step 순서대로 이동
- 같은 문제에서 반복 구간이 지정 횟수만큼 실행
- 평가 단계에서 Space 비활성/O-A-X 활성
- O/A/X 후 다음 문제 + 프로그램 첫 단계 복귀
- Program OFF 후 기존 Dapchigi Space 흐름 복원
- SOURCE BANK 및 기존 QA Gate 유지
