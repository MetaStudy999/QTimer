# QTimer Semantic Choice Marking v1

기준일: 2026-08-12

## 1. 목적

답치기 정답 공개 단계에서 사용자가 **시험에서 선택해야 할 선지**와 **부정형 문제의 정상 조건에 부합하는 선지**를 빠르게 구분하도록 돕는다.

이 기능은 정답을 미리 노출하는 힌트가 아니라 `reveal(정답 확인)` 단계의 피드백이다.

핵심 원칙:

> 빨강은 시험에서 선택할 정답, 파랑은 부정형 문제에서 정상 조건에 부합하는 비정답 선지.

---

## 2. 취소선 금지

Semantic Choice Marking v1은 **취소선을 사용하지 않는다.**

이유:

- `해당하지 않는 것은?`의 정답은 해당 범주에서 제외될 뿐 개념 자체가 틀렸다는 뜻이 아니다.
- `거리가 먼 것은?`의 정답도 지식 자체가 오류라는 뜻이 아니다.
- 취소선은 개념 자체가 폐기되거나 틀렸다는 인상을 줄 수 있다.

따라서 의미는 색상 + 배지로 전달하고, 모든 semantic-marked choice에는 `text-decoration-line: none`을 강제한다.

---

## 3. 의미 색상

### 빨강 — `● 선택`

의미:

- 현재 문제에서 시험 답안으로 선택해야 하는 정답
- 긍정형/부정형 여부와 관계없이 정답은 항상 빨강

표현:

- 빨간 글자
- 연한 빨간 배경
- 빨간 좌측 강조선/테두리
- `● 선택` 배지

### 파랑 — `✓ 부합`

의미:

- **부정형 문제에서** 정답이 아닌 나머지 선지
- 문제의 정상 조건에 부합하는 선지

`맞음`이라는 라벨을 사용하지 않는다.

이유:

- `틀린 것은?`에서는 파란 선지가 실제로 옳은 설명이다.
- `해당하지 않는 것은?`에서는 파란 선지가 해당 범주에 속한다는 의미다.
- 따라서 더 일반적이고 안전한 의미는 `부합`이다.

표현:

- 파란 글자
- 연한 파란 배경
- 파란 좌측 강조선/테두리
- `✓ 부합` 배지

---

## 4. 문제 유형 처리

### 4.1 긍정형 / 일반 단일정답 문제

예:

- 옳은 것은?
- 올바른 것은?
- 무엇인가?
- 알맞은 것은?

표시:

```text
① 일반
② 일반
③ ● 선택  ← 빨강
④ 일반
```

비정답은 중립 상태로 둔다.

### 4.2 오류 탐색형 부정문

예:

- 옳지 않은 것은?
- 틀린 것은?
- 잘못된 것은?
- 적절하지 않은 것은?

표시:

```text
① ✓ 부합  ← 파랑
② ✓ 부합  ← 파랑
③ ✓ 부합  ← 파랑
④ ● 선택  ← 빨강
```

### 4.3 제외/범주형 부정문

예:

- 아닌 것은?
- 해당하지 않는 것은?
- 포함되지 않는 것은?
- 속하지 않는 것은?
- 거리가 먼 것은?

표시는 오류 탐색형과 동일하다.

단, 파랑의 의미는 `참`이 아니라 **문제 조건에 부합**이다.

### 4.4 판별 불확실형

한 문장에 긍정 표현과 부정 표현이 함께 있어 자동 판별 신뢰도가 낮으면 보수적으로 처리한다.

```text
정답    → 빨강 `● 선택`
나머지  → 일반 표시
```

파란색을 억지로 적용하지 않는다.

---

## 5. 답치기 단계 연동

Semantic Marking은 `reveal` 단계에서만 활성화한다.

```text
preview   답 먼저 보기        → 선택지 semantic marking 없음
question  문제 회상           → 없음
mark      빈칸/회상 마킹      → 없음
reveal    정답 확인           → semantic marking 적용
```

따라서 색상이 회상 전에 정답을 유출하지 않는다.

---

## 6. 테마와의 우선순위

QTimer 학습 테마는 일반적인 표현(Presentation)을 담당한다.

Semantic Marking은 정답 피드백 의미(Semantics)를 담당한다.

```text
학습 테마
  ↓ 일반 상태
Semantic Marking
  ↓ reveal 단계에서 의미 색상이 우선
```

Semantic Marking은 문제/답 폰트, 크기, 일반 테마 설정을 삭제하거나 저장값을 변경하지 않는다.

---

## 7. 접근성

색상만으로 의미를 전달하지 않는다.

- 정답: `● 선택`
- 부합: `✓ 부합`
- 고대비 환경에서 테두리를 강화한다.
- 취소선은 사용하지 않는다.
- 모바일에서도 기존 choice 터치 영역을 유지한다.

---

## 8. 데이터 안전성

이 기능은 UI presentation layer다.

변경하지 않는 것:

- 973문항 SOURCE BANK
- 문제/정답 provenance
- 일반 Attempt
- Dapchigi O/A/X Attempt schema
- Settings schema
- 정답 번호

문제 유형 판별 결과도 SOURCE BANK에 쓰지 않는다.

---

## 9. 구현 기준

파일:

- `semantic-choice-marking-v1.js`
- `dapchigi-style-enhancements.js`에서 후행 로드

자동 검증:

1. 부정형 문제 reveal에서 정답 1개가 빨강 `target`인지
2. 나머지 선지가 파랑 `support`인지
3. 모든 semantic choice의 취소선이 `none`인지
4. 긍정형 문제에서는 정답만 빨강인지
5. reveal 이전에는 semantic marking이 없는지
6. SOURCE BANK/Attempt schema가 변경되지 않는지

---

## 10. 후속 검토 항목

현재 시험 직전 안정성을 위해 Settings schema를 늘리지 않는다.

실사용 확인 후 필요하면 환경설정 고급 영역에 다음을 추가할 수 있다.

- 의미 마킹: 자동(권장) / 정답만 / 끔
- `✓ 부합` 배지 표시 여부
- 의미 색상 접근성 팔레트

기본 원칙인 `빨강=선택`, `파랑=부합`, `취소선 없음`은 유지한다.
