# QTimer Dapchigi Focus Quick Settings v1

기준일: 2026-08-12

## 1. 목적

답치기 집중모드에서 전체 환경설정 화면으로 이동하지 않고 **문제 · 답 · 핵심어의 표시만 즉시 조절**한다.

핵심 원칙:

> 설정은 필요할 때만 잠깐 열고, 수정 결과는 실제 문제 화면에 즉시 보이며, 닫으면 다시 문제와 해설 중심 화면으로 돌아간다.

## 2. Focus Context Bar

```text
현재 범위 · 위치 · 단계      [범위 ⚙] [표시 Aa] [집중 종료 Esc]
```

- `범위 ⚙`: 과목/Chapter 등 학습 범위만 조절한다.
- `표시 Aa`: 문제/답/핵심어 Quick Settings를 연다.
- 두 패널은 동시에 열리지 않는다.
- `Esc`: Quick Settings가 열려 있으면 패널만 닫는다. 학습 세션은 종료하지 않는다.

범위와 표시 설정을 분리하여 설정 패널이 커지는 것을 방지한다.

## 3. Quick Settings UI

우측에 작은 floating drawer로 표시한다.

```text
┌──────────────────────────────┐
│ 빠른 표시 설정   ↶ 되돌리기 ✕ │
│ [문제] [답] [핵심어]          │
│                              │
│ 선택한 대상의 최소 설정       │
│                              │
│ 변경 즉시 저장 · 적용    Esc  │
└──────────────────────────────┘
```

전체 화면을 어둡게 가리는 modal로 만들지 않는다. 실제 문제 화면을 보면서 색과 글자 크기를 비교할 수 있어야 한다.

## 4. 문제 탭

조절 가능:

- 폰트 종류
- 폰트 크기
- 글자색
- 전체 문제 연한 형광펜 색상

집중모드에서는 다음 구조를 **고정 invariant**로 유지한다.

- 문제 전체 연한 형광 배경
- 강한 글자 계층
- 그 위에 핵심어 진한 형광 계층

따라서 Quick Settings에서 문제의 `전체 형광 강조 끄기`나 `강한 글자 계층 끄기`는 노출하지 않는다.

사용자가 실수로 Focus Reading의 시각적 계층 자체를 제거하는 것을 방지하기 위함이다.

문제 탭의 값은 기존 Settings v3 `dapchigi.question`과 같은 값을 사용한다. 별도의 중복 문제 설정을 만들지 않는다.

## 5. 답 탭

조절 가능:

- 폰트 종류
- 폰트 크기
- 글자색
- 형광펜 색상
- 볼드 On/Off
- 형광펜 On/Off

값은 기존 Settings v3 `dapchigi.answer`를 직접 사용한다.

따라서 집중모드에서 바꾼 답 표시와 일반 환경설정의 답 표시가 서로 어긋나지 않는다.

오른쪽 해설 패널의 `정답` 블록도 같은 답 글꼴/크기/글자색/형광색을 따라간다.

## 6. 핵심어 탭

기본값:

```text
문제 글꼴·크기 따라가기 = ON
핵심어 글자색 = 흰색
형광펜 = 문제 형광색에서 자동 파생
볼드 = ON
```

즉 기본 상태에서는 사용자가 핵심어 설정을 따로 관리할 필요가 없다.

필요한 경우 다음을 독립 조절한다.

- `문제 글꼴·크기 따라가기` On/Off
- 핵심어 전용 폰트
- 핵심어 전용 크기
- 글자색
- 형광펜 `자동 / 사용자 지정`
- 사용자 지정 형광펜 색상
- 볼드

`핵심어 자동값` 버튼은 다시 기본 상속 구조로 복원한다.

## 7. 즉시 적용과 되돌리기

모든 변경은 Apply 버튼 없이 즉시 반영하고 즉시 저장한다.

다만 즉시 저장만 제공하면 실수 복구가 어려우므로 Quick Settings를 열 때 현재 상태를 snapshot으로 잡는다.

- 패널을 연 뒤 변경이 생기면 `↶ 되돌리기` 활성화
- 누르면 **패널을 열기 전 상태**로 문제/답/핵심어 설정을 한 번에 복원
- 학습기록이나 현재 문제 위치는 변경하지 않음

이는 설정 속도와 안전성을 함께 확보하기 위한 장치다.

## 8. 저장 구조

### 문제 / 답

기존 Settings v3를 단일 진실 공급원(Single Source of Truth)으로 사용한다.

- 별도 중복 설정 생성 금지
- Settings v3 자동 저장/불러오기와 동일하게 동작

### 핵심어

집중모드 전용 presentation preference로 저장한다.

```text
localStorage key
qtimer-focus-quick-settings-v1
```

학습 state나 Dapchigi O/A/X attempt에는 넣지 않는다.

QTimer 전체 백업/복원에는 이 집중모드 표시 설정을 함께 포함한다.

## 9. 집중 설계에서 제외한 것

Quick Settings에는 다음을 넣지 않는다.

- 해설 전체 폰트 상세 설정
- 화면 배율 10단계
- 학습 색상 테마 전체 목록
- 데이터 백업/복원
- 문제 범위 선택
- O/A/X 학습 옵션

필요한 기능을 모두 한 패널에 넣으면 Quick Settings가 다시 일반 환경설정이 되기 때문이다.

현재 목표는 **실제 학습 중 자주 수정할 가능성이 높은 문제/답/핵심어 표시만 최소 비용으로 조절하는 것**이다.

## 10. 데이터 안전성

변경하지 않는다.

- 973문항 SOURCE BANK
- sourceAnswer / provenance
- 일반 Attempt
- Dapchigi O/A/X Attempt schema
- 문제 위치 / 회독 상태

Quick Settings는 presentation preference만 변경한다.

## 11. Browser QA 기준

- Focus Reading 밖에서는 Quick Settings가 보이지 않는가
- `범위`와 `표시` 패널이 동시에 열리지 않는가
- 문제/답/핵심어 3개 탭만 제공하는가
- 문제의 Focus full-highlight + strong-weight invariant가 유지되는가
- 문제 폰트/크기/글자색/형광색이 즉시 반영되는가
- 답 폰트/크기/글자색/형광색/볼드가 즉시 반영되는가
- 해설의 정답 블록이 답 설정을 따라가는가
- 핵심어가 기본적으로 문제 글꼴을 상속하는가
- 핵심어 독립 폰트/크기/색상/형광색 설정이 동작하는가
- `되돌리기`가 패널을 열기 전 상태로 복원하는가
- `Esc`가 Quick Settings만 닫고 답치기를 종료하지 않는가
- Dashboard 복귀 시 Quick Settings가 남지 않는가
- SOURCE BANK / attempt가 변경되지 않는가
